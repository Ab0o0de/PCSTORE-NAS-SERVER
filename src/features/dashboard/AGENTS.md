# Project Vision

PCSTORE NAS SERVER is not an OpenMediaVault customization.

OpenMediaVault is only the backend operating layer.

The final customer should experience a completely independent operating platform branded as PCSTORE NAS SERVER.

The software should be:

* Modern
* Professional
* Enterprise-grade
* Secure
* Fast
* Lightweight
* Modular
* Plugin-based
* Scalable
* Production Ready

The overall quality target is comparable to enterprise NAS platforms such as Synology DSM, TrueNAS, and Unraid, while remaining an original implementation.
